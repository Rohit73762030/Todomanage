# Todo Manager Application
A simple, clean, and extensible task management system built using Java.
The application allows users to create, update, delete, and monitor daily tasks
through an interactive console interface.
This project demonstrates strong fundamentals of object-oriented programming,
code organization, and scalable design practices.

##  Key Highlights
 Clean layered structure  
 Modular and maintainable code  
 Proper separation of concerns  
 Beginner friendly & extendable to enterprise level  
 
##  About The Project
The goal of this project is to design a practical system for managing todos
while applying core Java concepts such as classes, objects, collections,
encapsulation, and basic validations.
It serves as a foundation for future upgrades like REST APIs,
database persistence, and UI integration.

##  Features
 Create new tasks  
 Update existing tasks  
 Delete tasks  
 View all tasks  
 Structured and readable console workflow  
 Input validation and controlled operations  
 
##  Tech Stack
 **Language:** Java  
 **Build Tool:** Maven (if applicable)  
 **Architecture Style:** Layered / Modular
